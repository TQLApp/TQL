# TQL YouTrack Plugin

The TQL YouTrack Plugin adds support for YouTrack by JetBrains to Techie's Quick
Launcher, both self-hosted and YouTrack Cloud. With this plugin, you can search
issues with YouTrack's own query language, and find projects, agile boards,
saved searches and dashboards. You can create new issues in a project. And the
Microsoft Teams plugin can find YouTrack users to chat with or call.
